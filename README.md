#SSBS高中电视台任务抽奖系统
####这是一个专为上海星河湾双语学校高中电视台设计的任务分配与抽奖系统。系统基于 微信小程序 + 微信云开发构建。
##核心特性
身份绑定机制：预导入 57 名成员花名册，通过微信 OpenID 实现“一人一号”唯一绑定。
###动态权重算法：
初始权重：每位成员初始权重为 100。
###保底补偿：未中奖成员的权重在开奖后自动乘以 1.2，提高下次中奖概率。
###重置逻辑：若中签，该成员权重立即回落至 100。
###时间拦截系统：管理员可动态设置报名起止时间，非报名时段自动锁定。
###批量抽奖支持：支持单轮抽取多名中奖者，系统自动处理去重逻辑。
###管理后台：支持手动调整成员权重、实时监控报名人数、一键执行开奖。
