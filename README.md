# SSBS高中电视台任务抽奖系统

这是一个专为上海星河湾双语学校高中电视台设计的任务分配与抽奖系统，基于「微信小程序 + 微信云开发」构建。

## 核心特性

- 身份绑定机制：预导入成员花名册，通过微信 OpenID 实现“一人一号”唯一绑定。
- 多抽奖池：支持“前期 / 后期 / 主持 / 写作”四类独立任务池。
- 单池选择规则：每位用户同一时刻只能选择一个池子，但可取消并重新选择。
- 动态权重算法：
  - 初始权重：每位成员初始权重为 100。
  - 保底补偿：同池未中奖成员开奖后权重自动 ×1.2。
  - 中签归零：任意池中奖后，用户权重归零（跨池统一生效）。
- 时间拦截系统：管理员可动态设置报名起止时间，非报名时段自动锁定。
- 批量抽奖支持：支持单轮抽取多名中奖者，系统自动去重。
- 管理后台：支持手动调整成员权重、查看报名池子分布、按池开奖。
